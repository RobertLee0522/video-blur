# 影片追蹤模糊 (Windows / macOS)

在影片中框選要遮蔽的區域 (例如窗戶), 自動追蹤並模糊; 相機轉向時會跟著透視變形, 轉開再轉回來會自動找回。

## 安裝與執行

需要 Python 3.8+ (macOS 請用 python.org 或 conda 版本, 內建 Tk 比較穩定)

```bash
pip install -r requirements.txt
python app.py            # 或 python app.py 影片.mp4
```

建議安裝 `ffmpeg` (放在系統 PATH): 匯出時畫面直接送進 ffmpeg, 只壓縮一次成 H.264 (CRF 18, 約肉眼無損) 並保留原影片聲音;
沒有 ffmpeg 則用 OpenCV 輸出, 無聲音且畫質較低。解析度與幀率都與原片相同。
(Windows: `winget install ffmpeg`, macOS: `brew install ffmpeg`)

## 使用流程

1. **開啟影片**, 暫停在窗戶清楚的畫面
2. **新增目標**
   - 點四角 `Q`: 依序點窗戶四個角 (建議, 轉向時會正確透視變形)
   - 拖曳矩形 `N`
3. 按空白鍵播放, 綠框 = 追蹤中, 橘框 = 暫時遺失但仍在最後位置模糊
4. 不想再遮了: 選目標 → **從此幀取消追蹤+模糊** `S` (這幀之後不追蹤、不模糊, 之前保留)
   - 之後又要遮: 在該幀 **在此幀重新框選**, 或 **恢復追蹤** 移除取消點
   - 整段都不要: **刪除目標** `Delete`, 或 **模糊 開/關** `B`
5. 追歪了: 暫停 → 選目標 → **在此幀重新框選**, 此幀之後重新追蹤
6. **匯出影片** (會從頭完整追蹤一次, 不需先看完整片)

可 **儲存專案** (.json) 之後再載入修改。

## 設定

| 設定 | 預設 | 說明 |
|---|---|---|
| 外擴 % | 5 | 模糊範圍比追蹤框大一點, 容許追蹤誤差. 精準遮蔽可降到 2~3 |
| 遺失後保留(幀) | 5 | 追蹤遺失後仍在最後位置模糊幾幀, 超過就自動停止模糊 (畫面顯示紅色虛線框) |
| 最低可信度 % | 30 | 目前位置與框選當下外觀的相似度低於此值視為遺失, 避免模糊到另一扇相似的窗戶. 0 = 不檢查 |
| 追蹤解析度 | 960 | 追蹤運算用的寬度 (輸出一律為原解析度). 目標小、遠、細節少時改 1440 / 1920, 速度較慢 |
| 輸出編碼 | Mac: Apple 硬體 H.264; 其他: x264 | 只列出本機 ffmpeg 支援的編碼器. 軟體編碼畫質最好; Apple / NVIDIA 硬體編碼較快 |

「分析追蹤」只會處理從最早框選到最後取消點的片段; 匯出時已分析過的幀直接沿用結果, 不會重新追蹤。

| 快捷鍵 | 功能 |
|---|---|
| 空白鍵 | 播放 / 暫停 |
| ← / → | 前後一幀 (Shift: 1 秒) |
| N / Q | 新增矩形 / 四點目標 |
| S | 從此幀取消追蹤+模糊 |
| B | 模糊開關 |
| Delete / BackSpace | 刪除目標 |
| Esc | 取消框選; 四點模式右鍵退回一點 |

## 追蹤原理 (tracker.py)

- KLT 光流 + Homography 逐幀追蹤平面目標
- 定期 (目標在畫面邊緣時每幀) 用 ORB 特徵比對框選當下的樣板, 以 NCC 相似度挑較正確的位置, 修正漂移
- 追蹤遺失時用 ORB 全畫面搜尋找回
- 限制: 窗戶剛從畫面邊緣進來只露出一小條時可能要幾幀才找回; 大面積被遮擋或外觀大幅改變 (夜景亮燈) 時請手動重新框選
